<h4>４、下記の通りに、各項目を入力して、次へ</h4>

URI　：　https://github.com/eb-xiexinyue/EB_Tech_Training_2026.git

パスワード　：　<b>作成したtoken</b>

※セキュア・ストアに保管にチェックつける
